# Ingestion testing PoC

## Question

Does this platform meet minimum criteria to serve as front desk for our pipeline to work correctly?

## Candidates 

LINE, Discord, PWA

## Criteria

- [ ] Start count from opening an app, take <= 5 taps to finished and submit.
- [ ] Can upload an image or take an image.
- [ ] My location at the moment I log a meal is available without me typing it.
- [ ] screenshot or image must arrive safely and readable.

## Steps

1. Check available tools for each platform, do they support API or some programming way to sent information.
2. write simple script base on those method supported by platform to react when upload or take an image.
3. An image arrive safely and wait for processing to extract metadata.
4. check how location can be obtained: image metadata or another method.
5. check the result and record it down for comparison between them later.

## Time box

3 days, one platform per day.
